# Sikkerhet

Har du funnet et sikkerhetshull i HvaMenerPartiet, meld fra privat via [GitHub Security Advisories](https://github.com/Laaknor/HvaMenerPartiet/security/advisories/new) i stedet for å opprette en offentlig sak.

Beskriv hva du fant, hvordan det kan gjenskapes og hvilken del av løsningen det gjelder (den offentlige siden, admin eller bakgrunnsjobbene). Du får svar så snart som mulig, og vi avtaler sammen når hullet kan omtales offentlig.

Kontaktinformasjonen finnes også i [/.well-known/security.txt](https://www.rfc-editor.org/rfc/rfc9116) på nettstedet.

## Security policy (English)

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/Laaknor/HvaMenerPartiet/security/advisories/new). Do not open a public issue.
